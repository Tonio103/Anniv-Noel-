# Systèmes

Les briques transverses, utilisées par plusieurs apparitions ou par toute
l'expérience. À lire avant de toucher à une apparition individuelle si le
problème semble dépasser une seule scène.

- [`camera-drone.md`](./camera-drone.md) — le drone qui suit le cerf, le
  regard vers une apparition, l'arrêt du cerf, le choc caméra
- [`postfx.md`](./postfx.md) — assombrissement, teinte, distorsion,
  profondeur de champ
- [`audio.md`](./audio.md) — comment une scène déclenche un son
- [`cerf-et-empreintes.md`](./cerf-et-empreintes.md) — le cerf et ses
  empreintes (et pourquoi seul le cerf en a)
- [`terrain-foret.md`](./terrain-foret.md) — semis des arbres, dégagements,
  relief
- [`cadeaux-haltes.md`](./cadeaux-haltes.md) — la machine à états des
  neuf haltes-cadeaux, distincte de celle des apparitions
